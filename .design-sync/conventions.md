# Sculptor UI — как собирать экраны

Внутренний справочник OpenYard: радиоэлектронные компоненты, платы с
составами (BOM), серверы. Пользователи — инженеры и библиотекари; экраны
плотные, рабочие, без маркетинга. Весь текст интерфейса — по-русски,
названия полей таблиц компонентов — как в базе, латиницей (`Vendor PN`,
`Package`, `SMT_THT`).

## Каркас страницы

- Полная страница — всегда внутри `AppShell`: тёмная шапка с логотипом и
  глобальным поиском, слева рейл с группами, справа `main`. Внутри —
  `PageHeader`, затем `Panel`-ы; несколько панелей подряд — в `Stack`,
  две колонки — `Columns` (`main` — широкая слева, `aside` — справа).
- Страница списка: `PageHeader` (эйбров, заголовок, счётчик, главная
  кнопка) → `Panel` с `Toolbar` (поиск, фильтры `SelectField`,
  `ToolbarSpacer`, выгрузка) → `DataTable flow` → `Pager`.
- Карточка: `PageHeader mono` с номером детали и чипами → `Panel` с
  `Specs`; вкладки — `Tabs`.
- Форма: `Panel` → `FormGrid` (3 колонки у компонента, 2 у платы, 1 для
  узкой) → `FormBar` с кнопками. Ошибки сохранения — `Alert tone="error"`
  над формой.
- Пусто — `EmptyState`, а не пустая таблица.

## Стиль

- Цвета, отступы, скругления, шрифты — только CSS-переменные из
  `styles.css`: `--purple` (акцент, одна главная кнопка на экран),
  `--fault`, `--ok`, `--info`, `--ink`/`--muted`, `--surface`/`--bg`,
  `--line`; шаги `--s-1…--s-6`; `--r-sm/md/lg`, `--pill`. Свои числа
  цветов не вводить.
- Два шрифта: `--font-ui` (Verdana) для интерфейса и `--font-data`
  (Roboto Mono) для данных — номеров деталей, значений, дат. В
  `DataTable` это решает `kind: "pn"`, в `Specs` — сам компонент.
- Подписи полей и заголовки панелей — мелкие, капсом, с разрядкой: так их
  рисует CSS, писать их капсом в тексте не нужно.
- Кнопки и поля — «таблетки» (`--pill`). Главное действие —
  `Button variant="primary"`, отмена — `ghost`, удаление — `danger`
  последним.
- Статусы — `Chip`: события журнала `added`/`edited`/`gone`, служебные
  пометки `table` (моно), замены `replacement`, дубли `dup`.
- Тёмная тема — `data-theme="dark"` на `<html>`; компоненты
  перекрашиваются сами, отдельных вариантов не нужно.
- Ширина: колонки `Columns` и сетка `FormGrid` на 3 поля складываются на
  узких окнах (ниже ~1100 и ~1180 px) — это задумано.
